Connect task saving to the questionnaires

The actual task data saved successfully. Its export did not contain the return-URL field. The field and End of Survey redirect below are required for the submission tab to notify the original task tab after saving.

  1. In the existing receiver survey, open Survey Flow. In the Embedded Data element above the receiver block, add one text field named __js_fae_return_url. Leave its value unset so it is received from the task.
  2. Open the receiver question's JavaScript editor. Replace its entire contents with the code below, then save.

    View complete JavaScript
  3. In Survey Flow, add a Branch after the receiver block. Its conditions should be __js_fae_receiver_status Is Equal To verified AND __js_fae_return_url Is Not Empty. Inside that branch add End of Survey. Choose Customize → Override Survey Options → Redirect to a URL, and enter exactly:

    ${e://Field/__js_fae_return_url}

    Keep response recording enabled: leave Do NOT record survey response unchecked. Apply the Flow changes and Publish. Leave the default thank-you ending for probes without a return URL.

After publishing, run the shortened task test with both saves. It attempts one ZIP through DataPipe, then opens Qualtrics in a separate tab even if the DataPipe result is queued or unconfirmed. A stalled DataPipe request times out after 30 seconds. After Qualtrics submits, its receipt page should close the submission tab and the original task tab should continue to the questionnaires with id=QUALTRICS_TEST. If the browser blocks the tab, use Open submission window on the task page. Export the receiver CSV with all fields afterward for verification.
